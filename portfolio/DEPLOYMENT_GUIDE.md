# 🚀 Deploy Your Portfolio - Get a Shareable Link

## Option 1: Netlify Drop (FASTEST - 2 Minutes)

### Steps:
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag your entire `portfolio` folder onto the page
3. Wait 30 seconds for upload
4. Get your link: `https://random-name-12345.netlify.app`
5. **Share this link with anyone!**

### To Get a Custom Name:
1. Sign up for free Netlify account
2. Go to Site Settings > Change Site Name
3. Change to: `medesetbefkadu.netlify.app`

## Option 2: GitHub Pages (Professional)

### Steps:

1. **Create GitHub Account** (if you don't have one)
   - Go to [https://github.com/signup](https://github.com/signup)
   - Create account with username like `medesetbefkadu`

2. **Create New Repository**
   - Click "+" → "New repository"
   - Name it: `portfolio` or `medesetbefkadu.github.io`
   - Make it Public
   - Click "Create repository"

3. **Upload Your Files**
   - Click "uploading an existing file"
   - Drag all files from your portfolio folder
   - Click "Commit changes"

4. **Enable GitHub Pages**
   - Go to Settings → Pages
   - Source: Deploy from branch
   - Branch: main → / (root)
   - Click Save

5. **Get Your Link**
   - Your site will be live at:
   - `https://medesetbefkadu.github.io/portfolio/`
   - Or if repo name is `medesetbefkadu.github.io`:
   - `https://medesetbefkadu.github.io/`

## Option 3: Vercel (Fast & Free)

### Steps:
1. Go to [https://vercel.com/](https://vercel.com/)
2. Sign up with GitHub
3. Click "Add New" → "Project"
4. Import your GitHub repository
5. Click "Deploy"
6. Get link: `https://portfolio-username.vercel.app`
